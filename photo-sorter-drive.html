Google Drive set up ▸

One-time setup. In the Google Cloud console: create a project, enable the Google Picker API and Google Drive API, then under Credentials make an API key and an OAuth client ID of type Web application. Add the address you serve this page from (for example http://localhost:8000) to that client's Authorised JavaScript origins. The project number is under IAM & Admin → Settings.
