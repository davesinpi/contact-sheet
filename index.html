Use your own Google Cloud project

Only needed if you host this page yourself, or would rather connect through your own project. In the Google Cloud console: enable the Google Picker API and Google Drive API, then create an API key and a Web application OAuth client ID whose Authorised JavaScript origins include the address you serve this page from. Project number is under IAM & Admin → Settings. Values are stored only in this browser.
